# AK AI Studio

Create a completely new premium AI chatbot UI based on the website/reference URL I provide below.

REFERENCE URL:
when user send a message send webhook request of user messsage as raw body at this url[https://cme-community.app.n8n.cloud/webhook/AK]

IMPORTANT:

Use the provided URL only as visual/design inspiration. Do not copy copyrighted assets, branding, logos, text, or proprietary code from the reference website.

Build the chatbot from scratch with its own original design.

==================================================

==================================================

The chatbot name is:

AK

Display "AK" prominently at the top of the chatbot.

The AK branding should feel premium, minimal, futuristic, and professional.

Create a beautiful premium AI identity for AK using:

- elegant typography

- premium glass effects

- minimal AI-inspired iconography
